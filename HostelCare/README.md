# HostelCare - Hostel Maintenance Portal

> **A Mini Project Report Implementation**  
> **Course:** U21CS504 - Web Technologies Lab  
> **Institution:** Department of Computer Science and Engineering, KPRIET  
> **Author:** SHARU KHAN F K (25CSL18)

HostelCare is a web application that digitizes hostel maintenance workflows. Students can report complaints (Electrical, Plumbing, Cleaning, Furniture, Internet, Other) with location, priority, description, and optional file attachments. Wardens and administrators can review requests, transition statuses (`SUBMITTED` &rarr; `IN_PROGRESS` &rarr; `RESOLVED` / `REJECTED`) within transactional database boundaries, and audit every change.

---

## 🏛 System Architecture & Technology Stack

As described in Chapter 1.5, Chapter 3.1 & Figure 3.1 of the project report:

- **Front-End:** HTML5, CSS3, JavaScript (ES6), Bootstrap 5.3, Bootstrap Icons, Chart.js (`frontend/index.html`, `style.css`, `app.js`).
- **PHP Service (Port 8000):** PHP 8+ with PDO (`php-api/public/auth.php`, `issues.php`, `config/`). Handles student registration, login, and request creation/listing.
- **Java Service (Port 8080):** Java 17+, Jakarta Servlets 6, JDBC on Apache Tomcat 10.1+ (`java-service/src/.../StatusServlet.java`, `AuditServlet.java`). Handles administrator status updates and audit logs.
- **Authentication:** Shared HS256 JSON Web Token (JWT) valid for 24 hours. Tokens generated by PHP are verified identically by Java.
- **Database:** PostgreSQL 14+ (`database/schema.sql`) with tables: `users`, `maintenance_issues`, and `audit_logs`.

## 🚀 Quick Start (Instant Run)

You can launch the full application with the zero-dependency local runner:

```bash

# or:
node server.js
```

Then open your browser at:  
👉 **`http://localhost:5500`**

Both **PHP: Online** and **Java: Online** status indicators in the header navbar will be green!

## 🛠 Manual Setup with Native PHP, Tomcat & PostgreSQL

If you wish to run the native PHP and Tomcat services directly:

### 1. Database Setup (PostgreSQL)
```bash
psql -U postgres -f database/schema.sql
```

### 2. Run PHP Service (Port 8000)
```bash
cd php-api
php -S localhost:8000 -t public
```

### 3. Build & Deploy Java Service (Port 8080)
```bash
cd java-service
mvn clean package
cp target/hostel-java.war $CATALINA_HOME/webapps/
$CATALINA_HOME/bin/startup.sh
```

### 4. Open Frontend
Open `frontend/index.html` in your browser or run:
```bash
php -S localhost:5500 -t frontend
```

## 🧪 Verified Functional Requirements & Test Cases

Matches Chapter 6.1 (Table 6.1):

- **FR1 & Test Case 1:** Student registration with name, email, password >= 6 characters. Duplicate emails rejected with 409.
- **FR2 & Test Case 4:** Secure login with hashed password comparison, returning signed 24h JWT.
- **FR3 & Test Case 6:** Report maintenance issue with title, category, location, priority, description, and optional attachment.
- **FR4 & Test Case 7:** Student dashboard displays only their own requests; Admin dashboard displays all requests with reporter names.
- **FR5:** 4 summary counters (Total, Submitted, In Progress, Resolved) and interactive Chart.js doughnut chart.
- **FR6 & Test Case 11:** Admin moves requests to `IN_PROGRESS`, `RESOLVED`, or `REJECTED`.
- **FR7 & FR8:** Status changes are recorded in `audit_logs` with old status, new status, remarks, actor name, and timestamp. Viewable via the Details modal timeline.
- **FR9 & Test Cases 8, 9, 10:** Unauthorized requests without tokens return 401; student access to admin endpoints returns 403.
- **FR10 & Test Case 15:** Session persistence across page reloads using localStorage; clean session wipe on logout.
